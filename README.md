## Как обновить подключение

Если соединение перестало работать:

1. Скопируйте актуальный адрес сервера.
2. Зайдите в панель подключений.
3. Найдите свои подключения.
4. Скопируйте конфиги подключений.
5. Вставьте новые конфиги в приложения.
6. Измените отпечаток на firefox.
7. Сохраните изменения и переподключитесь.

---

*Если подключение работает исправно, менять настройки не требуется.*
